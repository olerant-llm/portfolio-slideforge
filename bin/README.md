# OfficeCLIを別途配置する

PowerPointの読込にOfficeCLIを使います。元環境で確認した版は1.0.136です。公式プロジェクトの配布物からOSに合う版を取得し、Windowsはこのフォルダへ `officecli.exe`、macOS/Linuxは `officecli` として配置してください。

出典: [OfficeCLIの公式配布](https://github.com/iOfficeAI/OfficeCLI/releases)。元環境の確認版は `v1.0.136` です。

この公開物にはOfficeCLI本体を含めません。取得先と利用条件を確認してから実行してください。新しい版の出力形式との互換性は未確認です。
